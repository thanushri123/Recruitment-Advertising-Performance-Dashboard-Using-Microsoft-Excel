# Recruitment Advertising Performance Dashboard

## Project Overview

This project focuses on analysing recruitment advertising campaign performance using Microsoft Excel.

The dashboard provides insights into advertising expenditure, impressions, clicks, applications and campaign efficiency across multiple advertising channels.

This project uses synthetic data created for educational and portfolio purposes. It is not actual customer data.

## Tools & Technologies
- Microsoft Excel
- Excel Formulas
- Data Cleaning
- KPI Analysis
- Data Visualization

## Key Performance Indicators
- Total Advertising Spend
- Total Impressions
- Total Clicks
- Total Applications
- Click-Through Rate (CTR)
- Cost Per Click (CPC)
- Cost Per Application (CPA)
- Application Conversion Rate

## Dataset

The dataset contains 112 illustrative campaign records across four advertising channels:
- Google Ads
- LinkedIn
- Indeed
- Facebook

## Analysis Performed
- Campaign performance analysis
- Channel-wise performance comparison
- Advertising cost analysis
- Application conversion analysis
- KPI tracking and reporting
- Basic data quality checks

## Data Quality Checks
- Checked for missing and duplicate records.
- Verified impressions, clicks and applications.
- Checked for non-negative advertising expenditure.
- Validated calculated performance metrics.

## Business Objective

The objective is to identify effective advertising channels, understand campaign efficiency and support data-driven recruitment advertising decisions.
